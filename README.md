# CCNA

Study materials and lab configs for the Cisco CCNA 200-301 v1.1 exam.

- [`ccna-200-301-v1.1/`](ccna-200-301-v1.1/) — blueprint-mapped reference
  notes and CLI procedures, one file per exam domain.
- [`packet-tracer-lab/`](packet-tracer-lab/) — a complete Packet Tracer
  topology and paste-ready device configs to build and test the blueprint
  objectives hands-on.
- [`configs/`](configs/) — standalone production-style configs (e.g. a
  Day-0 access switch build).
- [`real-world/`](real-world/) — CCNA vs Real World working notes: real
  on-the-job issues tied back to CCNA knowledge. Edit
  `CCNA_vs_RealWorld.md`, then run `node real-world/build_docx.js` to
  rebuild the `.docx`.
